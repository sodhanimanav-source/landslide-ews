BHU-KAAL / Landslide EWS - SIH26001
====================================

This folder is your complete project, including git history.
Branch: feat/bhukaal-engine  (2 commits ahead of main)

RUN IT
------
  cd landslide-ews
  py -m pip install -r requirements.txt
  py -m uvicorn app.main:app --reload --port 8080

Then open:
  http://localhost:8080                            the dashboard
  http://localhost:8080/docs                       interactive API
  http://localhost:8080/api/v2/hindcast/cyclone-remal    the demo endpoint

WHAT TO LOOK FOR ON THE MAP
---------------------------
  - legend bottom-left:  "BHU-KAAL ALERT LEVEL"
  - badge top-right:     "ENGINE LIVE - 18 sites - N evacuate - N zero-warning"
  - button top-right:    "FORECAST 24h"  (toggles observed vs forecast mode)
  - click any corridor:  popup leads with WARNING TIME LEFT, not a risk score

WHAT CHANGED
------------
Three bugs fixed (all were breaking the live app):
  1. routes/risk.py passed rainfall= to a function taking rain_24h.
     /api/risk-zones/ raised TypeError on every request.
  2. routes/alerts.py built Alert(location_name=...) but the model has
     corridor_name + risk_score. Every POST failed.
  3. The committed landslide.db had a pre-rename schema, so inserts failed
     even after fix 2. app/migrate.py now reconciles it on startup.

New engine in app/engine/ - four layers:
  physics/      infiltration + slope stability, Monte Carlo
  friction/     rate-and-state chi -> how many hours of warning remain
  disturbance/  window of vulnerability after hill cutting
  decision/     cost-based thresholds, alert ladder, CAP 1.2 output
  evaluation/   POD/FAR/TSS/PR-AUC/Brier + lead-time metrics

Full detail is in README.md.

BEFORE YOU PRESENT
------------------
  - Tune the cost ratios in app/engine/decision/cost.py (ASSET_CLASSES).
    Hospital currently trips EVACUATE at 3.85% - defensible, but it will
    fire often. Decide your own numbers and say in the deck that you tuned
    them.
  - Read the "Honest limitations" section of README.md and be ready to
    state those before a judge finds them.
  - Do NOT quote the old v1 model's "ROC-AUC 0.9822". It is scored on data
    generated by the same hand-written formula it learned.
